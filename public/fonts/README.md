# Bundled fonts

These typefaces ship with NoSidian so they work offline. They come from Google Fonts
(https://fonts.google.com) and are licensed under the SIL Open Font License 1.1.
Only the regular (400) and bold (700) weights are included to keep the app small.
`fonts.css` is generated from the Google Fonts API; the catalog is in `src/core/fonts.ts`.
