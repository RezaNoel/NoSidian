# Roadmap

Desktop (Windows .exe) and Android (.apk) ship together from the same version.

- [x] **Phase 0: Foundation.** Workspace, Tauri shell, 14-locale i18n with strict coverage test, themes and glass tokens, RTL layout, accessibility basics, settings store, CI for .exe and .apk.
- [ ] **Phase 1:** Onboarding (language first, experience level, personalization, vault setup), file tree, editor and reader, tabs, resizable sidebars, mobile bottom bar, per-vault profiles.
- [ ] **Phase 2:** Indexing (search, tags, backlinks, recent, starred, calendar, daily notes), quick switcher, command palette, hotkeys, Settings modal with search.
- [ ] **Phase 3:** Rich rendering, view modes (split, mindmap, kanban, slides), properties, snapshots, export.
- [ ] **Phase 4:** PDF workspace.
- [ ] **Phase 5:** Todos and Project Mode with two-way Markdown sync.
- [ ] **Phase 6:** Flashcards and SRS (FSRS, SM-2).
- [ ] **Phase 7:** Dashboard hubs and 18 widgets.
- [ ] **Phase 8:** Knowledge graph.
- [ ] **Phase 9:** Zen Focus Studio, audio mixer, ambient effects.
- [ ] **Phase 10:** Media Shelf.
- [ ] **Phase 11:** 3D companion pet and economy.
- [ ] **Phase 12:** Terminal, developer CSS/JS, MCP bridge.
- [ ] **Phase 13:** Mobile hardening and store-ready packaging.
